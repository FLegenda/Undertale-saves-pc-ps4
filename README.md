# Undertale-saves-pc-ps4
Complete Undertale save files collection for jailbroken PS4 and PC (CUSA09415 / Apollo Save Tool) — Genocide, Neutral &amp; Pacifist routes.

--------------------------------------------------------------------------------------------------------------------------------------------

This file is for *Undertale* save data on the PS4. You don’t need to mix it with PC save files, though doing so won’t cause any issues. To use this save file, you will first need to download the 
Apollo Save Tool (https://pkg-zone.com/details/APOL00004). Prepare a USB flash drive and plug it into your console. Open the Apollo Save Tool, select "HDD saves," choose *Undertale* from the list
 of games, and select "Export decrypted save files." Next, plug the USB drive into your PC; you will see a "PS4" folder. Navigate to the following path: `PS4\APOLLO`. Open the folder located there,
 go into the *Undertale* folder, and delete all of its contents. Then, take the *Undertale* save file you downloaded—specifically the `undertale.sav` file—and move it into that folder. Finally,
 plug the USB drive back into your PS4, open the Apollo Save Tool, select "USB Saves," refresh the list, go to *Undertale*, and choose the option to copy the save data to the HDD. You’re all set!
 Good luck!

---------------------------------------------------------------------------------------------------------------------------------------------

How to install for PC:
1. Go to the local disk (C:)
2. Then into the Users folder
3. Open your user folder (mine is the Administrator folder because I have only one user)
4. Then into the AppData folder
5. Into the Local folder
6. And look for the UNDERTALE folder and drop the save you need into it
